# ADR 0007 — 경비 계정과목 대분류 15종 선정 근거

## Status
Accepted (2026-05-24)

## Context

세무사가 영수증을 처리할 때 최종적으로 필요한 정보는 **"이 지출이 어떤 계정과목인가"** 이다.
계정과목이 없으면 AI가 부가세 공제 여부를 판단해줘도 회계 장부에 기록할 수 없고,
더존·세무사랑 같은 회계 프로그램으로 내보낼 수 없다.

계정과목 체계는 한국채택국제회계기준(K-IFRS), 일반기업회계기준(K-GAAP),
세무회계 실무 관행이 혼재하며 수백 개의 소분류가 존재한다.
MVP에서 모든 소분류를 지원하면 LLM 프롬프트가 복잡해지고 테스트 케이스가 폭발적으로 늘어난다.

## Decision

**대분류 15종만 지원한다.** 소분류와 업무용/비업무용 구분은 추후 단계에서 추가한다.

선정된 15종과 각각의 근거:

| 계정과목 | 선정 근거 | 대표 영수증 예시 |
|----------|-----------|-----------------|
| **복리후생비** | 직원 식대·간식·의료비. 중소 세무법인 영수증 중 빈도 1위 | 편의점, 카페, 약국 |
| **접대비** | 부가세법 시행령 §42 한도 규정 대상. 리스크 플래그와 연동 필수 | 음식점, 골프장, 주류 |
| **소모품비** | 사무용품·청소용품 등 당기 비용 처리 소모품 | 문구점, 마트 (소액) |
| **여비교통비** | 출장·이동 비용. 택시 영수증이 전체 영수증 중 높은 비중 차지 | 택시, 주유소, KTX |
| **통신비** | 업무용 휴대폰·인터넷 요금. 개인/법인 구분 이슈 있음 | 통신사, 인터넷 요금 |
| **광고선전비** | 마케팅·홍보 비용. 스타트업·소상공인 영수증에 빈도 높음 | SNS 광고, 현수막 |
| **수선비** | 사무실·장비 수리. 임차인 부담 수선 범위 세무 이슈 | 용역업체, AS 센터 |
| **임차료** | 사무실·주차장·장비 임대료. 세금계산서 수취 의무 확인 대상 | 부동산 임대, 주차장 |
| **교육훈련비** | 직원 교육·세미나·자격증. 비용 인정 요건 있음 | 학원, 온라인 강의 |
| **도서인쇄비** | 도서·잡지·인쇄물. 소액이지만 세무사 실무에서 자주 등장 | 서점, 인쇄소 |
| **회의비** | 사내 회의 음료·식사. 복리후생비와 구분 기준: 외부인 참석 여부 | 카페, 음식점 (내부) |
| **세금과공과** | 재산세·자동차세·면허세 등 법적 의무 납부금 | 지방세, 협회비 |
| **보험료** | 업무용 차량보험·화재보험·배상책임보험 | 보험사 영수증 |
| **외주용역비** | 프리랜서·용역 계약. 3.3% 원천징수 여부 확인 필요 | 디자인, 개발, 번역 |
| **미분류** | 위 14종으로 분류 불가한 케이스. 세무사가 직접 확정 | 복합 품목, 불명확 가맹점 |

## 소분류를 이 단계에서 제외한 이유

1. **LLM 정확도 트레이드오프**: 선택지가 30종 이상이면 LLM이 유사 계정과목 간 혼동 빈도 증가
2. **세무사 UX**: 대분류 15종은 한 화면에 드롭다운으로 표시 가능. 소분류까지 포함하면 UI 복잡도 급증
3. **단계적 고도화 가능**: 대분류가 확정된 뒤 특정 계정(예: 여비교통비)에만 소분류를 추가하는 것이 전체 동시 도입보다 리스크가 낮음

## 업무용/비업무용 구분을 이 단계에서 제외한 이유

- 접대비 한도 계산(연간 1,800만원·매출액 기준)은 월별 누계 데이터가 필요
- 차량 관련 비용의 업무 사용 비율은 운행일지와 연동해야 정확
- 두 케이스 모두 **부가세 집계 API**(다음 Sprint)가 먼저 구현된 후 자연스럽게 추가 가능

## Consequences

**긍정적 결과**
- LLM 프롬프트가 단순해 structured output 정확도 높음
- 테스트 케이스를 15종 기준으로 작성 가능
- 세무사가 검토 화면에서 즉시 이해하고 수정 가능

**부정적 결과·완화 방법**
- `미분류` 비율이 높으면 세무사 수작업 증가 → 초기 운영 데이터 수집 후 규칙 추가로 보완
- 소분류 미지원으로 더존 완전 자동 import 불가 → export 기능 추가 시 소분류 매핑 레이어 삽입 예정

## 참고 자료

- 법인세법 시행규칙 별표 3: 업종별 접대비 한도액
- 부가가치세법 시행령 제42조: 접대비 매입세액 불공제
- 한국세무사회 실무 가이드라인 (2024)
- 일반기업회계기준 제17장: 무형자산 및 기타비용 분류
