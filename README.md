# Tax-Copilot

세무사를 위한 AI 기반 업무 자동화 워크플로우 엔진.

> AI는 판단 후보를 제시할 뿐이며, 모든 최종 판단은 세무사가 합니다.

## Status

Work in progress — Phase 0 (Repository Skeleton)

## Stack

- **Backend**: FastAPI, SQLAlchemy 2.0 async, Alembic
- **AI Workflow**: LangGraph + PostgreSQL Checkpointer
- **RAG**: Qdrant + Gemini Embedding
- **Vision**: Gemini Vision
- **Queue**: Celery + Redis
- **DB**: PostgreSQL 16, Redis 7
- **Frontend**: Next.js (Week 5)
